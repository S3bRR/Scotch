# Build 13 Steam validation

Local candidate, tested November 14, 2026 on Apple M5 Pro, macOS 27.2.1.
No user bottle was changed and no account credentials were entered.

## Installation and launches

The real Install Steam view-model action was exercised in a newly created,
isolated bottle using a copy of the installed runtime. The official silent
installer exited before Steam was pinned. The initial launch downloaded Valve's
client packages and reached `WaitingForCredentials - OK` without a manual
restart or backend change. Its vendor web helper was left intact.

Subsequent cold launches reached a fresh sign-in state with DXVK, DXMT,
D3DMetal and Zink. The checks reject Chromium GPU crash loops, ANGLE driver-query errors,
fatal CEF errors and WineDbg/unhandled exceptions. With software UI rendering
alone, the Metal engine's CEF sandbox breakpoint loop was reproduced; Steam's
Metal-only CEF sandbox compatibility switch removed it. Stock Wine retains that
sandbox. No macOS security or TLS setting changes.

`bash scripts/test_steam.sh` also verifies Steam/game argument separation,
shutdown behavior, option deduplication, unchanged vendor updates, restoration
of the old Scotch helper, and retention of recovery copies. CI runs these local
checks without downloading Steam. The live install/network check is opt-in.

`bash scripts/test_updates.sh` passed authentication/tamper/expiry tests, staged
activation and repair, idle gates, runtime routing, replay/architecture rejection,
prefix snapshot/restore, external catalogs, and future/corrupt metadata
preservation. The native graphics profile is unchanged from build 12, whose
rendering matrix is recorded in `1.2.4-validation.md`.

## Final artifact and remaining checks

The generated local receipt `.release/build13/Validation.txt` records the final
DMG checksum, mounted-bundle/source audit and real signed updater/relaunch test.
It is written after packaging and does not publish a release.

Desktop automation could not reliably access Wine's window. These live checks
establish the client's sign-in state and absence of the reproduced failures;
visible layout, account login and games remain user testing. Replace Scotch.app
after quitting Scotch and Steam. Keep Application Support and custom bottle
folders to preserve bottles, saves and settings.

No commit, push, tag, release or public feed deployment is part of this build.
