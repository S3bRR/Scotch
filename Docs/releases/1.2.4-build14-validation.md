# Build 14 validation

Local candidate tested November 14, 2026 on Apple M5 Pro, macOS 27.2.1.
No existing user bottle was modified. No account credentials were entered.
No commit, push, tag, public release or feed publication is authorized.

## Steam

The user confirmed that Steam's visible window now works. An isolated fresh
Install Steam action also completed the official installer, saved its pin,
downloaded the first client update and reached sign-in without a manual restart
or backend switch. Cold launches reached fresh sign-in states with DXVK, DXMT,
D3DMetal and Zink, with GPU compositing enabled and no reproduced CEF fatal
error, GPU crash loop or Wine debugger.

Sign-in logs alone did not establish visible rendering in build 13. Build 14
repairs WineMac child-surface hosting and uses a path-scoped matched DXMT loader
for Steam's CEF helper. It registers both winemetal PE stubs in fresh prefixes.
Valve's executables remain intact; a diagnostic wrapper was rejected because
the Steam bootstrap checksum check correctly detected it. Steam still needs a
CEF-only Windows sandbox compatibility option. No macOS security or TLS
settings are changed.

Evidence: `.build/steam-proof/fresh-registered-final14.log`,
`.build/steam-proof/steam-complete-final14.log` and
`.build/steam-policy-release14.log`.

## Real graphics and Auto

The pinned downloads, hashes, extraction, native bridge, targeted repair and
normal Wine.app launch path passed. GPU readback passed for DXVK/DXMT in both
Windows architectures and D3DMetal in x64. Zink passed real OpenGL 4.5+ shader
execution/readback in x86/x64. Combined Direct3D and additive Zink passed for
DXVK/DXMT in x86/x64 and D3DMetal in x64. No OpenGL version override was used.

Auto identified and launched actual OpenGL and statically imported DirectX 12
test applications, selected Zink/D3DMetal with recovery protection, verified
GPU rendering and recorded the selected setup without automatically marking it
working. Executables now launch directly through Wine.app with their own
working directory. Shell-associated files retain the shell route.

Parser/policy fixtures passed architecture, normal/delay/local imports,
malformed/incomplete inspection, fingerprints, custom launch settings,
manual/confirmed priorities, missing runtimes, idle gates, atomic launch lease
transfer, snapshots and future profile preservation. Scoped process cleanup
stopped a fixture belonging to one Wine prefix while preserving another.
Runtime availability is simulated only for metadata transition fixtures.

Desktop UI inspection confirmed architecture/API/reason display, saved a manual
backend override, and verified Bottle Runtime's bottom-toolbar placement.

Evidence: `.build/live-graphics-release14.log` and
`.build/program-graphics-final14.log`. Native support is `scotch-graphics-2`;
`GraphicsSupport.tar.xz` SHA256 is
`a458c9e3fb90eb0c7af67304657d69ab2c2e21e6ed0305378cc6f3a2b820c75f`.
The native patch was also applied to a clean pinned Wine tree and its six
modified source files matched those used for compilation.

retention of an existing verified overlay, and rollback on Zink checksum or
dependency failure. All backend payloads installed and rendered in the live
matrix. The published missing-overlay URL is no longer requested.

Update regressions passed signed feed authentication, tamper/expiry/replay and
architecture rejection, staged activation, damaged-set repair, idle exclusion,
runtime routing, complete prefix snapshot/restore, external catalogs and
future/corrupt metadata preservation.

Evidence: `.build/installer-regressions-final14.log` and
`.build/update-verification-release14.log`.

Final artifact checks run after packaging. The local receipt

candidate signatures. Candidate feeds remain unpublished.

## Remaining manual coverage

Auto infers compatibility, not measured performance. Launchers, incomplete and
ambiguous detection keep the bottle setting. Backend selection remains shared
by the bottle and requires idle Wine processes plus a complete recovery copy,
including installed games. Large bottles need adequate free space.

still need manual testing. Quit Scotch and Steam before replacing Scotch.app.
