# Build 16 release validation

Build 16 packages the user-tested build 15 runtime, Steam, Windows 11 font and
Auto behavior for release as 1.2.4. Native support remains scotch-graphics-2,
SHA256 a458c9e3fb90eb0c7af67304657d69ab2c2e21e6ed0305378cc6f3a2b820c75f.
The build 14 and 15 reports retain the real GPU, fresh-Steam, Windows 11 font,
inherited Auto and save-preservation evidence on M5 Pro / macOS 27.2.1.

The mounted DMG now contains only Scotch.app and the Applications shortcut.
ScotchGraphicsSources.tar.xz and its checksum are separate release assets. They
contain the pinned WineForge/Mesa originals, complete Scotch source, patches,
licenses and build instructions. SourceAvailability.txt in the app links to the
same release and exact source asset. Third-party licenses are retained.

Release preparation repeats the helper/selection/update regression checks,
builds all three release executables and verifies the finished installer with
scripts/verify_release_artifacts.py. That audit checks both asset checksums,
the two-item DMG layout, mounted app/CLI/resources/QuickLook/signatures, native
support parity and exact corresponding source against the release checkout.

The repository's established sequence is a PR merged to main after CI, a clean
checkout build of the release commit, a version tag and a GitHub release named
Scotch v1.2.4. User downloads retain the Scotch.dmg / Scotch.dmg.sha256 names.
Complete native sources are additional optional assets. The generated artifact
receipt and release body record the final hashes, commit and CI run; those
values are added after packaging rather than embedding a checksum in its own
corresponding source.

The final app is also exercised through the real signed replacement/relaunch
probe using unique fixture data and a loopback feed. It must preserve the save
and bottle catalog and clear the installed offer. Signed feeds are prepared
locally; public assets must exist and pass verification before feed deployment.

No account credentials or existing user bottle is used by these probes. Other
games, Macs, minimum macOS and clean-machine Gatekeeper behavior retain the
manual-testing limits stated in the release notes. Ad-hoc signing is unchanged.
